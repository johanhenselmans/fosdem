Open Source Embedded Development with Qtopia

Lorn will explain the development procedure including development of new device support through the use of device configurations using Qtopia 4 Open Source Edition as well as the Greenphone SDK.

Qtopia is at the forefront of the Linux Embedded gui development world.

Qtopia has always been open source, and with the release of Qtopia 4 Open Source Edition, more source code than every before has been released as Open Source.

Trolltech believes in the power of the GPL, which is why we release Qt and Qtopia under a dual license scheme, so the free code always remains free. Other companies say they embrace open source, but really only want to leverage development they don't have to pay for, and only deliver a partial framework.

Now Trolltech has (soon) released Qtopia 4 Open Source Edition, developers can once again develop free software for an up to date Qtopia, which includes Qtopia Phones, such as the Greenphone, released at the end of 2006.

Qtopia 4 is even easier to get started than before, as now there is only one package to download, configure and compile. Lorn will explain the development procedure including development of new device support through the use of device configurations.

He will also explain the Greenphone SDK, so all developers can develop free applications for Qtopia Phone Edition.
