Event Track Day Room Start time Duration
Polishing X11 and making it shiny X.org Sunday AW1.124 13:00 00:45

Daniel Stone

Daniel Stone saves the world by making input on X awesome, and funds this by working at Nokia.

Daniel Stone is an X server developer and the current X input maintainer, currently working as an X developer at Nokia, for their internet tablets. He was tricked into doing Debian X packaging back in 2002, and started a gradual decline into hacking on the X server and started fixing input due to what can only be described as monumental stupidity. He is a current member of the X.Org Foundation Board of Directors, and enjoys talking about himself in the third person.
