Ruby+Rails Developer Room

Room: AW1.126

Ruby and Rails

The "Ruby and Rails" devroom will set-up for the third time a 1 day program with presentations on Ruby and Ruby and Rails. We have invited some core developers and will also solicit abstracts for submitted presentations.

Ruby is a dynamic, open source programming language with a focus on simplicity and productivity. It has an elegant syntax that is natural to read and easy to write.

Ruby on Rails is an open-source web framework that's optimized for programmer happiness and sustainable productivity. It lets you write beautiful code by favoring convention over configuration.
