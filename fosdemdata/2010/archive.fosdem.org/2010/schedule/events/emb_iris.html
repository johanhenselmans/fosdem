Iris, a new capability-based microkernel OS

Iris is a new capability-based microkernel operating system.

Being a microkernel system, it is easy to work on things which on other systems need kernel programming (and root priviledges). Being a capability-based system, it allows transparent virtualization of everything. This leads to improved security to such a degree, that the user can really trust the computer. A capability-based system also allows easy monitoring of communication. Another nice feature is that the user can swap target devices under a running program.
