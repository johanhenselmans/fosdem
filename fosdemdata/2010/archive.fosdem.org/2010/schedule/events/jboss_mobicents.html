Mobicents

JAIN SLEE is a specification (JSR 240) of a real-time and event-based platform in JAVA. It can be seen as the equivalent of the JEE but for real-time and oriented to Telecommunication, especially NgIN and IMS.

However, it could be used for any other JAVA applications requiring performance. In this talk we will introduce the JAIN SLEE throug the Mobicents project, the first certified-JAINSLEE 1.1 and open source application server from RedHat.

The presentation will cover:

  • The JAIN SLEE component model and the event-driven programming
  • The mobicents JAIN SLEE 1.2 features and the introduction to EclipSLEE the Service Creation Environment on Eclipse
  • IMS example: we will show how we can implement a SIP registrar with JAIN SLEE. We will also show how a JAIN SLEE AS might be integrated in an IMS infrastructure.
