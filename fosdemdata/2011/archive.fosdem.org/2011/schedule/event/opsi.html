Microsoft Windows Management with OPSI

Today we have a very mixed environment of systems, those systems runs GNU/Linux, FreeBSD, OpenBSD, Windows (tm), MacOSx.

While we have free software tools to manage GNU/Linux and BSD systems, managing Microsoft Windows systems is still the most difficult part.

OPSI is a free software tool to manage the complexity of Microsoft Windows Environments. What make it special is that it's not again managing Microsoft Windows by unix guys, but managing it the way the Windows administrators works.

OPSI provide a complete solution to deploy, manage and update to windows system from Windows 2000 to Windows 7, it also manage the licences for all the deployed software.

There is now collaboration between the OPSI project and the fusioninventory project to make OPSI use the fusioninventory client to manage the hardware and software inventory.
